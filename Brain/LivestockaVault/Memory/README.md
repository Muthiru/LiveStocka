# LiveStocka
LiveStocka is a **cattle management system** that helps farmers and ranchers track animal health, reproduction, milk production, and overall farm operations.

## Target Audience
- Small‑to‑mid sized farms
- Farm managers needing a single view for all livestock data
- Users comfortable with web or mobile interfaces

## Technology Stack
- **Frontend:** Nuxt 3, Vue 3, TypeScript, Tailwind CSS
- **Backend:** Supabase (PostgreSQL, Auth, Storage)
- **Deployment:** Vercel (frontend) and Supabase (database)
- **Security:** Row‑level security in the database, OAuth + email auth
